--------------------------------------------------------------------------------
3. SERVER DEPLOYMENT COMMANDS (Kal Server/aaPanel Pe Update Karte Waqt Ye Steps Karein)
--------------------------------------------------------------------------------

Step 1: Files upload karne ke baad terminal me ye command chalayein:
   php artisan migrate --force

Step 2: Agar server par build karna ho (warna local se public/js/app.js aur public/js/*.js upload kar sakte hain):
   npm run prod

Step 3: Cache clear karein:
   php artisan config:clear
   php artisan route:clear
   php artisan cache:clear
